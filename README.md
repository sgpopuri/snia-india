# SNIA India 2026-27 Program Plan

> **Status as of 22 May 2026:** Program plan drafted; no artifacts shipped yet. The timeline below reflects a realistic start from **July 2026**, with reduced cadence and an extended horizon through **November 2027**.

SNIA India is the **vendor-neutral technical voice for storage in India's regulator-driven, India-Stack-scale, AI-native digital economy.** This repository contains the program plan for SNIA India's reactivation — earning the right to host **SDC India** by shipping technical artifacts at SNIA-grade quality and contributing to global SNIA TWGs.

## Adjusted scope (May 2026 decision)

The original 12-month plan (Mar 2026 – Feb 2027) targeted ~36 outbound artifacts. Given the late start and realistic member bandwidth, we have:

- **Extended the horizon** to 17 months (Jul 2026 → Nov 2027).
- **Reduced the cadence** to ~25 outbound artifacts: 4 podcasts, 4 webinars, 8 blogs, 2 white papers, 3 T/E/N meetups, 3 press digests, 1 annual report.
- **Pushed SDC India** to late 2027 / H1 2028 (announcement mid-2027; event follows).
- **Kept the TWG engagement targets** (2 full seats + 1 India-led TWG charter) but with relaxed quarterly quotas.

The plan is designed so that if the team finds its rhythm faster, we can pull deliverables forward. Conversely, the fallback rules in [`operations.md`](operations.md) handle slips without losing credibility.
